# repository guidelines

this repository has two independent applications: `frontend/` and `backend/`. see the `agents.md` in each directory for application-specific guidelines. run application commands from the relevant directory.

## commit & pull request guidelines

the available git history contains only `init`, so it does not establish a detailed commit convention. use short, descriptive, imperative commit subjects. pull requests should describe the change and its verification, link relevant issues, and include screenshots for visible ui changes.
